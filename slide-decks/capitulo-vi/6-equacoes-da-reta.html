Trajetórias Lineares

Como Descrever uma Reta no Espaço?

No \(R^2\): uma equação linear \(ax + by + c = 0\) define uma reta.

No \(R^3\): uma equação define um plano. Para uma reta, precisamos de outra abordagem.

Problema: Traçar rota de drone, tirolesa, míssil — tudo precisa de uma descrição linear em 3D.

"No \(R^3\), uma equação só não faz verão (pra reta). Paramétrica é a salvação!"

Equações da Reta no Espaço

Trajetórias Definidas: Diferente do Plano!

Forma Vetorial: \(\quad \vec{X} = \vec{P_0} + t\vec{v}\)

Forma Paramétrica: \(\quad \begin{cases} x = x_0 + ta \\ y = y_0 + tb \\ z = z_0 + tc \end{cases}\)

Onde \(\vec{P_0} = (x_0, y_0, z_0)\) é um ponto na reta e \(\vec{v} = (a,b,c)\) é o vetor diretor.

Alternativa: Reta como interseção de dois planos não paralelos.

Simulador: Desenhando Retas no Espaço

\(P_0=(x_0,y_0,z_0)\), \(\vec{v}=(a,b,c)\)

0 0 0
1 1 1

Ajuste \(P_0\) e \(\vec{v}\) para ver a reta se orientar no espaço 3D.

Relatório: Encontros em 3D

Posições Relativas (Retas em \(R^3\)):

  • Paralelas: Vetores diretores paralelos.
  • Concorrentes: Se interceptam em um ponto.
  • Coincidentes: Mesma reta.
  • Reversas: Não se interceptam e não são paralelas. (NOVIDADE do \(R^3\)!)

Não assuma que trajetórias que se cruzam em mapas 2D o farão no 3D. A altitude (Z) é tudo!

Debriefing: Dominando as Linhas do Espaço

A reta em \(R^3\): paramétrica reina, reversas adicionam complexidade estratégica.
