9. Cada equação linear com duas incógnitas representa uma reta no plano. A solução do sistema é o ponto onde as retas se encontram.

Analise os seguintes sistemas sem resolvê-los completamente:

Se as razões entre os coeficientes de x e y são diferentes, as retas são concorrentes (um único ponto de interseção).

a) $\begin{cases} 2x + 3y = 5 \\ 4x - y = 10 \end{cases}$
- Qual a razão entre os coeficientes de $x$?
- Qual a razão entre os coeficientes de $y$?
- Qual a razão entre os termos independentes?
- As razões são diferentes?
- Qual o tipo de sistema?

Se as razões de x e y são iguais, mas a razão do termo independente é diferente, as retas são paralelas (sistema impossível).

b) $\begin{cases} x + 2y = 4 \\ 2x + 4y = 10 \end{cases}$
- Qual a razão entre os coeficientes de $x$?
- Qual a razão entre os coeficientes de $y$?
- Qual a razão entre os termos independentes?
- As razões são diferentes?
- Qual o tipo de sistema?

Se todas as razões (incluindo a do termo independente) forem iguais, as retas são coincidentes (infinitas soluções).

c) $\begin{cases} 3x - y = 2 \\ 6x - 2y = 4 \end{cases}$
- Qual a razão entre os coeficientes de $x$?
- Qual a razão entre os coeficientes de $y$?
- Qual a razão entre os termos independentes?
- As razões são diferentes?
- Qual o tipo de sistema?

Dica: Se você tentar resolver um sistema impossível por substituição, chegará a algo absurdo como 0 = 6.

Verificação: No item (b), você percebeu que a segunda equação é apenas a primeira multiplicada por 2, exceto pelo resultado final?
