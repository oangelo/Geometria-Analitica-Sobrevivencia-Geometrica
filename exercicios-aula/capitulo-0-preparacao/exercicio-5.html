5. Proporções são igualdades entre duas razões. Elas nos permitem prever valores desconhecidos com base em uma relação constante.

Trabalhe com as seguintes proporções:

Para encontrar o termo desconhecido, utilizamos a "multiplicação cruzada".

a) $\frac{2}{5} = \frac{x}{20}$ → $5x = 2 \cdot 20$ → $x = \frac{\text{}}{5} = \text{}$

b) $\frac{3}{x} = \frac{9}{12}$ → $9x = 3 \cdot 12$ → $x = \frac{\text{}}{9} = \text{}$

Resolva os problemas de Regra de Três:

Regra de Três Direta: se uma grandeza aumenta, a outra também aumenta.

a) Se 3 litros de combustível movem um veículo por 45 km, quantos litros são necessários para 135 km?
3L → 45km | xL → 135km $\rightarrow$ $x = \frac{\text{} \cdot 3}{45} = \text{}$ L

Regra de Três Inversa: se uma grandeza aumenta, a outra diminui.

b) Se 2 operários constroem um muro em 6 dias, quanto tempo levarão 3 operários para fazer o mesmo muro?
2 op → 6 dias | 3 op → x dias $\rightarrow$ $x = \frac{\text{} \cdot 6}{3} = \text{}$ dias

Verificação: No item (b), o tempo diminuiu com o aumento de operários? Se sim, a lógica inversa está correta.
