# Exercícios de Aula

Exercícios para resolver durante a aula, com acompanhamento do professor.

## Estrutura

Os exercícios de aula seguem um formato diferente dos exercícios de casa:
- Arquivo único por lista
- Exercícios mais curtos e diretos
- Foco em prática imediata do conteúdo apresentado

## Como usar

1. Navegue até o capítulo/tema desejado
2. Abra o arquivo HTML no navegador
3. Resolva os exercícios durante a aula

## Organização por Capítulo

```
exercicios-aula/
├── capitulo-i/     # R² e espaço vetorial
├── capitulo-ii/    # Vetores
├── capitulo-iii/   # Produtos escalar e vetorial
└── ...
```
