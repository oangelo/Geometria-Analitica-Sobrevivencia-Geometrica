Retas Coincidentes: O Mesmo Caminho

O objetivo deste exercício é reconhecer geometricamente um sistema com infinitas soluções. Dois grupos de sobreviventes mapearam rotas de abastecimento. O grupo $A$ descreveu a rota pela equação $3x + 2y = 12$. O grupo $B$ descreveu outra rota pela equação $6x + 4y = 24$. Os coordenadores querem saber se as rotas são diferentes ou se na verdade descrevem o mesmo caminho.

(a) Escreva o sistema de equações formado pelas duas rotas.

(b) Tente resolver o sistema por eliminação. Multiplique a primeira equação por 2 e subtraia da segunda. O que acontece?

(c) Desenhe no papel ambas as retas. Dica: encontre dois pontos de cada reta (por exemplo, quando $x = 0$ e quando $y = 0$) e verifique se coincidem. O que isso significa praticamente para os dois grupos de sobreviventes?

DICA DE SOBREVIVÊNCIA

Quando você multiplica a primeira equação por 2, obtém $6x + 4y = 24$. Compare atentamente com a segunda equação.

ACESSO NÍVEL: SUPERVISOR

Resolução:

(a) O sistema é:

$$\begin{cases} 3x + 2y = 12 \\ 6x + 4y = 24 \end{cases}$$

(b) Multiplicando a primeira equação por 2:

$6x + 4y = 24$ (equação I multiplicada)

Subtraindo da segunda equação:

$(6x + 4y) - (6x + 4y) = 24 - 24$

$0 = 0$

Isso é sempre verdade! Portanto, o sistema tem infinitas soluções.

(c) Análise geométrica:

Para a primeira equação $3x + 2y = 12$:

- Quando $x = 0$: $y = 6$ → ponto $(0, 6)$

- Quando $y = 0$: $x = 4$ → ponto $(4, 0)$

Para a segunda equação $6x + 4y = 24$:

- Quando $x = 0$: $y = 6$ → ponto $(0, 6)$

- Quando $y = 0$: $x = 4$ → ponto $(4, 0)$

As duas retas passam pelos mesmos pontos, ou seja, são a mesma reta (coincidentes).

Resposta: As duas rotas descrevem o mesmo caminho. O sistema é possível e indeterminado (SPI), com infinitas soluções.
