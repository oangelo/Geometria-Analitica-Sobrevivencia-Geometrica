Defesa do Perímetro: Sistema, Ângulos e Frações

Objetivo: Este exercício integra os 4 conceitos: Álgebra, Frações, Sistemas e Trigonometria. Você calculará a defesa de um perímetro usando sistemas de equações, ângulos de visão e frações de recursos.

O perímetro de um acampamento tem forma triangular com lados $a$, $b$ e $c$. Sabe-se que o lado $a$ é $\frac{3}{2}$ do lado $b$, e o lado $c$ é $10$ metros menor que o lado $a$. O perímetro total é $80$ metros. Em cada vértice, uma torre de vigia cobre um ângulo de $120°$.

(a) Monte um sistema de equações para encontrar $a$, $b$ e $c$.

(b) Resolva o sistema encontrando os três lados.

(c) Desenhe no papel o triângulo e verifique se ele é válido (a soma de dois lados deve ser maior que o terceiro).

(d) Se uma torre de vigia no vértice entre os lados $a$ e $b$ avista um ponto no lado oposto a $30$ metros de distância, formando um ângulo de $30°$ com o lado $a$, qual é a altura da torre?

(e) Os recursos de defesa são distribuídos proporcionalmente aos lados: $\frac{1}{4}$ para o lado $a$, $\frac{1}{3}$ para o lado $b$ e o restante para o lado $c$. Calcule quantos metros de cada lado recebem recursos (o total de recursos cobre $60$ metros).

DICA DE SOBREVIVÊNCIA

Para montar o sistema, traduza cada frase em uma equação. "O lado $a$ é $\frac{3}{2}$ do lado $b$" vira $a = \frac{3}{2}b$. "O lado $c$ é $10$ metros menor que $a$" vira $c = a - 10$. O perímetro é $a + b + c = 80$. Para a altura da torre, use $\tan(30°) = \frac{\text{altura}}{\text{distância ao longo do lado}}$.

ACESSO NÍVEL: SUPERVISOR

Resolução passo a passo:

(a) O sistema é:

$$\begin{cases} a = \frac{3}{2}b \\ c = a - 10 \\ a + b + c = 80 \end{cases}$$

(b) Substituindo as duas primeiras na terceira:

$$\frac{3}{2}b + b + (\frac{3}{2}b - 10) = 80$$

$$\frac{3}{2}b + b + \frac{3}{2}b - 10 = 80$$

$$4b = 90$$

$$b = 22{,}5$ metros

$$a = \frac{3}{2} \cdot 22{,}5 = 33{,}75$ metros

$$c = 33{,}75 - 10 = 23{,}75$ metros

(c) Verificação do triângulo:

$a + b = 56{,}25 > 23{,}75 = c$ ✓

$a + c = 57{,}5 > 22{,}5 = b$ ✓

$b + c = 46{,}25 > 33{,}75 = a$ ✓

(d) $\tan(30°) = \frac{h}{30}$, logo $h = 30 \cdot \frac{\sqrt{3}}{3} = 10\sqrt{3} \approx 17{,}32$ metros.

(e) Recursos para $a$: $\frac{1}{4} \cdot 60 = 15$ metros.

Recursos para $b$: $\frac{1}{3} \cdot 60 = 20$ metros.

Recursos para $c$: $60 - 15 - 20 = 25$ metros.

Verificação: $15 + 20 + 25 = 60$ metros. Confere!
