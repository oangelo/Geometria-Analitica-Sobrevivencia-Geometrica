> MANUAL DE SOBREVIVÊNCIA: SISTEMAS LINEARES

Situação: Você está na Zona Devastada. Recursos são escassos, decisões precisam ser rápidas e precisas. Muitas vezes, você precisa equilibrar duas restrições simultâneas: água e comida, mão-de-obra e tempo, combustível e distância. Cada par de restrições forma um sistema de equações lineares.

O que é um Sistema Linear?

Um sistema de equações lineares com duas variáveis é um conjunto de duas equações que devem ser satisfeitas simultaneamente. Cada equação representa uma restrição do mundo real.

$$\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$$

Método da Substituição

Quando usar: Quando uma das equações já isola uma variável facilmente ou quando os coeficientes são simples.

Passos:

(1) Isole uma variável em uma das equações.

(2) Substitua essa expressão na outra equação.

(3) Resolva a equação resultante com uma variável.

(4) Volte à expressão isolada para encontrar a outra variável.

(5) Verifique a solução nas duas equações originais.

Método da Eliminação

Quando usar: Quando os coeficientes são alinhados ou podem ser facilmente alinhados por multiplicação.

Passos:

(1) Alinhe os coeficientes de uma variável (multiplicando as equações se necessário).

(2) Some ou subtraia as equações para eliminar uma variável.

(3) Resolva a equação resultante.

(4) Substitua o valor encontrado em qualquer equação original para achar a outra variável.

(5) Verifique a solução.

Interpretação Geométrica

Cada equação linear com duas variáveis representa uma reta no plano cartesiano. A solução do sistema é o ponto onde as retas se encontram:

Retas concorrentes: Se cruzam em um único ponto → Sistema Possível e Determinado (SPD) — solução única.

Retas paralelas: Nunca se cruzam → Sistema Impossível (SI) — nenhuma solução.

Retas coincidentes: São a mesma reta → Sistema Possível e Indeterminado (SPI) — infinitas soluções.

Regras de Sobrevivência

⚠ REGRA 1: Sempre verifique sua solução substituindo nas equações originais. Na Zona Devastada, um erro de cálculo pode custar recursos preciosos.

⚠ REGRA 2: Quando o contexto envolve pessoas, objetos ou recursos inteiros, a solução deve fazer sentido no mundo real. Frações de pessoas não existem.

⚠ REGRA 3: Se você obter uma igualdade absurda (como $0 = 5$), o sistema é impossível. Se obter uma identidade (como $0 = 0$), o sistema tem infinitas soluções.

Boa sorte, sobrevivente. A matemática é sua aliada na Zona Devastada.
