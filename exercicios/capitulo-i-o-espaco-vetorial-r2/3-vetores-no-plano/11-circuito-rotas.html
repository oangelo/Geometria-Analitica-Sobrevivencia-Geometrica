CIRCUITO DE ROTAS: QUANDO A SOMA DÁ ZERO

Uma patrulha sai do abrigo $A$, segue até o posto de suprimentos $B$, depois à torre de vigia $C$, visita o ponto de coleta $D$ e retorna ao abrigo $A$. O comandante quer confirmar que o circuito é fechado — ou seja, a patrulha realmente volta ao ponto de partida. O objetivo deste exercício é verificar se a soma dos deslocamentos é o vetor nulo $\vec{0}$ e refletir sobre o significado do vetor nulo.

Os deslocamentos são: $\overrightarrow{AB} = (3, 2)$, $\overrightarrow{BC} = (-1, 4)$, $\overrightarrow{CD} = (-4, -1)$ e $\overrightarrow{DA} = (2, -5)$.

(a) Calcule a soma $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA}$. O resultado é o vetor nulo?

(b) Desenhe no papel: partindo de $A$, encadeie os quatro vetores pela regra do triângulo (ponta-cauda). O último vetor deve retornar ao ponto $A$. Se não retornar, o circuito tem uma "sobra".

(c) Agora considere outra patrulha com três deslocamentos: $\vec{p}_1 = (2, 3)$, $\vec{p}_2 = (4, -1)$ e $\vec{p}_3 = (-5, -2)$. A soma é $\vec{0}$? Se não, qual é o vetor de "sobra"? Para onde a patrulha terminou em relação ao abrigo?

DICA DE SOBREVIVÊNCIA

Some todas as componentes $x$ e todas as componentes $y$ separadamente. Se ambas forem zero, o circuito é fechado e a soma é $\vec{0}$. Se não, o vetor resultante indica onde a patrulha terminou em relação ao ponto de partida.

ACESSO NÍVEL: SUPERVISOR

(a) Componente $x$: $3 + (-1) + (-4) + 2 = 0$. Componente $y$: $2 + 4 + (-1) + (-5) = 0$. A soma é $\vec{0} = (0, 0)$. O circuito é fechado!

(b) No esboço, os quatro vetores encadeados formam um polígono fechado — a seta final liga $D$ de volta a $A$. Isso é a representação geométrica da propriedade $\sum \overrightarrow{d_i} = \vec{0}$.

(c) Componente $x$: $2 + 4 + (-5) = 1$. Componente $y$: $3 + (-1) + (-2) = 0$. A soma é $(1, 0) \neq \vec{0}$. O circuito não é fechado — a patrulha terminou 1 unidade a leste do abrigo. Para voltar, precisaria percorrer o vetor oposto $(-1, 0)$.

$$\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA} = (3, 2) + (-1, 4) + (-4, -1) + (2, -5) = (0, 0) = \vec{0}$$ $$\vec{p}_1 + \vec{p}_2 + \vec{p}_3 = (2, 3) + (4, -1) + (-5, -2) = (1, 0) \neq \vec{0}$$ $$\text{Circuito fechado} \iff \sum \overrightarrow{d_i} = \vec{0}$$

Reflexão: O vetor nulo é o selo de aprovação de um circuito bem planejado. Se a soma não for $\vec{0}$, a patrulha não voltou ao abrigo — e na Zona Devastada, passar a noite fora é um convite para problemas com mutantes. Sempre verifique a soma antes de enviar a equipe.
