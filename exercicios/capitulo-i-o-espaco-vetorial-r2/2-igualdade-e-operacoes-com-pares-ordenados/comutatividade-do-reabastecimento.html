COMUTATIVIDADE DO REABASTECIMENTO

O objetivo deste exercício é verificar experimentalmente a propriedade comutativa da soma de pares ordenados e entender por que ela é uma consequência direta da comutatividade da soma de números reais.

Uma operação de reabastecimento envia equipes a partir de dois depósitos: o Depósito Norte em $N(1, 4)$ e o Depósito Sul em $S(-3, 2)$. O comando testa duas ordens de soma para planejar o ponto de encontro.

(a) Calcule $N + S = (1, 4) + (-3, 2)$ e $S + N = (-3, 2) + (1, 4)$. Os resultados são iguais? Use a igualdade de pares ordenados para verificar.

(b) Por que a comutatividade da soma de pares ordenados é uma consequência da comutatividade da soma de números reais? Explique usando o cálculo componente a componente.

(c) Teste com outro par de sua escolha: escolha $A(a_1, a_2)$ e $B(b_1, b_2)$ com valores numéricos quaisquer. Verifique que $A + B = B + A$. A propriedade sempre vale?

DICA DE SOBREVIVÊNCIA

A soma componente a componente é $(a, b) + (c, d) = (a + c,\; b + d)$. Na parte (b), lembre que $a + c = c + a$ para quaisquer números reais. Essa propriedade se "transfere" para os pares ordenados.

ACESSO NÍVEL: SUPERVISOR

(a) $N + S = (1, 4) + (-3, 2) = (1 + (-3),\; 4 + 2) = (-2, 6)$. $S + N = (-3, 2) + (1, 4) = (-3 + 1,\; 2 + 4) = (-2, 6)$. Os resultados são iguais: $(-2, 6) = (-2, 6)$ ✓

(b) A soma de pares ordenados é feita componente a componente: $(a, b) + (c, d) = (a + c,\; b + d)$. Como $a + c = c + a$ e $b + d = d + b$ (comutatividade dos reais), temos $(a + c,\; b + d) = (c + a,\; d + b)$, que é exatamente $(c, d) + (a, b)$. A comutatividade dos pares é herança direta da comutatividade dos números reais.

(c) Exemplo: $A(5, -7)$ e $B(-2, 3)$. $A + B = (5 + (-2),\; -7 + 3) = (3, -4)$. $B + A = (-2 + 5,\; 3 + (-7)) = (3, -4)$. Iguais. Sim, a propriedade vale para quaisquer pares ordenados.

$$(a, b) + (c, d) = (a + c,\; b + d) = (c + a,\; d + b) = (c, d) + (a, b)$$
