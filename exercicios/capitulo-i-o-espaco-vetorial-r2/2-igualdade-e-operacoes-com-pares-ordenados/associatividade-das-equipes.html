ASSOCIATIVIDADE DAS EQUIPES

O objetivo deste exercício é verificar experimentalmente a propriedade associativa da soma de pares ordenados: a forma de agrupar as parcelas não altera o resultado.

Três equipes de reconhecimento reportam suas posições de patrulha: Equipe Alfa em $A(2, 1)$, Equipe Bravo em $B(-1, 3)$ e Equipe Charlie em $C(4, -2)$. O comando quer somar as três posições para determinar o "centro operacional" combinado.

(a) Calcule $(A + B) + C$: primeiro some $A + B$, depois some o resultado com $C$.

(b) Calcule $A + (B + C)$: primeiro some $B + C$, depois some $A$ ao resultado.

(c) Compare os resultados de (a) e (b). Eles são iguais? Por que isso ocorre, em termos das operações com números reais componente a componente?

DICA DE SOBREVIVÊNCIA

Cada soma é componente a componente. Na parte (a), calcule $A + B$ primeiro e depois some $C$. Na parte (b), calcule $B + C$ primeiro e depois some $A$. Na parte (c), expandha ambas as expressões e observe que $(a + b) + c = a + (b + c)$ para números reais.

ACESSO NÍVEL: SUPERVISOR

(a) $A + B = (2, 1) + (-1, 3) = (1, 4)$. Então $(A + B) + C = (1, 4) + (4, -2) = (5, 2)$.

(b) $B + C = (-1, 3) + (4, -2) = (3, 1)$. Então $A + (B + C) = (2, 1) + (3, 1) = (5, 2)$.

(c) Ambos resultam em $(5, 2)$. Isso ocorre porque a associatividade dos reais garante que $(a_1 + b_1) + c_1 = a_1 + (b_1 + c_1)$ e o mesmo para a segunda componente. O agrupamento não afeta o resultado.

$$\bigl((a, b) + (c, d)\bigr) + (e, f) = (a, b) + \bigl((c, d) + (e, f)\bigr) = (a + c + e,\; b + d + f)$$
